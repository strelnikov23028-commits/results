# Cartões — карточки для португальского

Приложение для проверки себя по списку слов: на лицевой стороне картинка,
на обороте слово и переводы на двух языках (RU + EN) с примерами фраз.
Прогресс и статистика считаются локально в браузере.

**Открыть:** https://taksa1973.github.io/results/cartoes-pt.html
Файл самодостаточный — работает и с диска двойным кликом, без интернета
(картинки при этом подтянутся только при сети).

## Что умеет

| Функция | Как работает |
|---|---|
| Знаю / не знаю | Кнопки ✓ и ✗ или стрелки `←` `→` |
| Вернуться назад | Кнопка ↩ или `Backspace` — откатывает и оценку, и статистику |
| Подсказка | «Показать подсказку» → первая буква и число букв: `c····` |
| Озвучка | Иконка динамика, голос `pt-BR` из системы |
| Перемешать | Тасует **оставшиеся** карточки, пройденные не трогает |
| Без повторов | Очередь строится один раз — за подход слово встретится ровно раз |
| Сохранение | Пишется в localStorage при каждом ответе; закрыл вкладку — вернёшься на то же место |
| Обнуление | Только кнопкой «Обнулить всё» в разделе «Статистика» |
| Конец колоды | Экран «Слова закончились» со счётом знаю / ещё изучаю и списком незнакомых |

Плюс: интервальное повторение (SM-2) — забытое возвращается назавтра,
знакомое уходит на всё более длинные интервалы; статистика по дням и частям речи.

## Структура

```
flashcards-pt/
├── app_template.html   ← шаблон интерфейса (правим его, не index.html)
├── build.py            ← вшивает words.json в HTML → index.html
├── fetch_images.py     ← подбирает картинки к словам
└── data/
    ├── words.json                    ← готовая колода (её читает build.py)
    ├── ru_overlay.json               ← русские переводы + запрос для поиска картинки
    └── source_speakingbrazilian.json ← сырой список с сайта
```

## Как добавить слова

1. Дописать слова в `data/words.json` — формат записи:

```json
{
  "id": 101,
  "pt": "cachorro",
  "en": "dog",
  "ru": "собака",
  "pos": "nouns",
  "examples": [{"pt": "O cachorro está dormindo.", "en": "The dog is sleeping."}],
  "imgQuery": "dog pet",
  "image": null,
  "credit": null
}
```

`imgQuery` — запрос на английском, по нему ищется фото.
Поставь `null`, если слово картинкой не передать (предлоги, союзы, артикли) —
тогда карточка покажет фразу с пропуском вместо фото.

2. Подтянуть картинки и пересобрать:

```bash
python3 fetch_images.py      # только для новых, где image = null
python3 build.py             # собрать index.html
```

## Про картинки

Фото приходят из **Openverse** (индексирует Flickr, Rawpixel, Wikimedia и др.).
Ключ скрипт получает сам при первом запуске и кладёт в `data/openverse_creds.json` —
вводить ничего не нужно.

Из результатов поиска выбирается тот кадр, где слова запроса встречаются
в заголовке и тегах, — иначе выдача слабо связана со смыслом.
Отдельный фильтр отсекает медицинский и анатомический материал: фотоархивы
им наполнены, и запрос «young adult person» однажды вернул клиническое фото.

Если качество какого-то кадра не устраивает — поправь `imgQuery` в `data/words.json`,
обнули у этой карточки `image`, и прогони `python3 fetch_images.py`.

Можно подключить Pexels как альтернативу (ключ бесплатный, 200 запросов/час):

```bash
PEXELS_API_KEY=твой_ключ python3 fetch_images.py --force
```
